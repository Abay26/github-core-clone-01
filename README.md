A standalone, GitHub-compatible git forge in one Node.js process: git smart HTTP (upload-pack v2, receive-pack v0), the REST v3 API, GraphQL v4 and MCP, all served from its own in-memory store with no UI, no outside service and no git binary.

## Run it

```sh
node --experimental-strip-types main.ts
```
